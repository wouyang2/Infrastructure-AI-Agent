Production Request Lifecycle

The durable handoff chain for Infrastructure AI Agent in an AWS-style deployment.

Golden path

  1. Browser submits request and media to FastAPI.
  2. FastAPI uploads media bytes to S3.
  3. FastAPI writes run metadata, prompt/notes, settings, and S3 media references to PostgreSQL/RDS.
  4. FastAPI enqueues an RQ job in Redis/ElastiCache with run_id.
  5. Worker loads run details from PostgreSQL and media from S3.
  6. Worker executes the agent graph and writes progress/results to PostgreSQL.
  7. API reads progress/results and returns them to the UI.

Ownership table

DataOwner
Image/video bytesS3
Prompt, notes, asset, runtime settingsPostgreSQL/RDS
Queued task pointerRedis/ElastiCache + RQ
Inspection progress and final reportPostgreSQL/RDS
Generated report files or annotated imagesS3, referenced by PostgreSQL

Rule

Redis should coordinate work. PostgreSQL should preserve truth. S3 should preserve files.
