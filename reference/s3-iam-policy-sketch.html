S3 IAM Policy Sketch

A starting point for least-privilege permissions for the Infrastructure AI Agent media bucket.

What the app needs

The API/worker needs permission to upload and read inspection media under one prefix. It should not have permission to manage all AWS resources or all buckets.

Example shape

{
  "Version": "2012-10-17",
  "Statement": [
    {
      "Effect": "Allow",
      "Action": [
        "s3:PutObject",
        "s3:GetObject",
        "s3:DeleteObject"
      ],
      "Resource": "arn:aws:s3:::infra-agent-media-dev/inspection-media/*"
    },
    {
      "Effect": "Allow",
      "Action": "s3:ListBucket",
      "Resource": "arn:aws:s3:::infra-agent-media-dev",
      "Condition": {
        "StringLike": {
          "s3:prefix": "inspection-media/*"
        }
      }
    }
  ]
}

Production note

For production, prefer an IAM role attached to the deployed service over hard-coded access keys. Local development can use AWS CLI credentials or environment variables temporarily.
