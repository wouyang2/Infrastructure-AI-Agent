AWS Deployment Map

A quick reference for moving the Infrastructure AI Agent from local Docker Compose toward AWS.

NeedLocalAWS
Web/APIFastAPI containerECS service behind a load balancer
Background jobsRQ worker containerECS worker service
SQL persistencePostgreSQL containerRDS for PostgreSQL
Queue/cache/progressRedis containerElastiCache Redis/Valkey
Image/video filesartifacts/uploadsS3 bucket and prefix
SecretsLocal .envSecrets Manager
PermissionsLocal keys/profileIAM task role

Deployment rule of thumb

Move stateful services first: S3, RDS, and ElastiCache. Then move stateless compute: API and worker containers.
