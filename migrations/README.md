# Database Migrations

Alembic owns production schema changes for the SQL persistence layer.

Run the latest migration against the database selected by `DATABASE_URL`:

```bash
python3 -m storage.migrate upgrade
```

Create a new autogenerated migration after changing `storage/models.py`:

```bash
alembic revision --autogenerate -m "describe change"
```

Local tests and quick demos can still use `init_database()` with SQLite. For
production-style deployment, run migrations before starting API and worker
processes.
