Lesson 0004 · Real S3 run

To use real S3, your app needs a destination and permission.

This lesson connects the AWS ideas to the exact workflow in this project: authenticate locally, provision an S3 bucket and IAM policy, point the app at that bucket, then run one upload.

The four moving parts

1. Credentials

Your local machine proves to AWS who you are. This can come from AWS CLI/profile or temporary environment variables.

2. Provisioning

A script creates the bucket, encryption, public access block, tags, and least-privilege IAM policy.

3. App config

Environment variables tell FastAPI/RQ to use S3 media storage instead of local disk.

4. Smoke upload

A tiny test image goes through the same storage interface the real inspection uploads use.

Why credentials are separate from app config

AWS_S3_MEDIA_BUCKET tells the app where to store files. It does not prove the app is allowed to write there.

AWS_ACCESS_KEY_ID, an AWS profile, or an IAM role proves the caller identity. IAM policies decide what that identity can do.

Do not paste AWS keys into chat or commit them to git. Set them in your local terminal, local ignored .env, or use an AWS profile.

The project workflow

Dry run first: shows what would be created.

python3 scripts/aws/provision_s3_media.py \
  --region us-east-1 \
  --create-ecs-role

Apply when ready: creates AWS resources.

python3 scripts/aws/provision_s3_media.py \
  --region us-east-1 \
  --create-ecs-role \
  --apply

Point the app at S3:

MEDIA_STORAGE_BACKEND=s3
AWS_S3_MEDIA_BUCKET=infra-agent-media-<account-id>-us-east-1
AWS_REGION=us-east-1
AWS_S3_MEDIA_PREFIX=inspection-media
AWS_S3_PRESIGN_EXPIRES_SECONDS=900

Upload one test image:

python3 scripts/aws/smoke_s3_media_upload.py

What success looks like

The smoke upload prints an S3-style key, such as:

backend=s3
key=inspection-media/smoke/s3-smoke.png
file_path=s3://infra-agent-media-.../inspection-media/smoke/s3-smoke.png
preview_url=https://...

That means the storage layer is no longer dependent on the API container’s local filesystem.

Retrieval practice

Question: If the app has AWS_S3_MEDIA_BUCKET configured but no AWS credentials, what happens?

Show answer

The app knows the target bucket name, but AWS rejects the request because the caller has not authenticated. Destination config is not permission.
