# Mission: AWS For Production Applications

## Why
Learn AWS by applying it directly to the Infrastructure AI Agent project, so cloud services feel like practical application infrastructure instead of abstract certification vocabulary.

## Success looks like
- Explain what AWS commonly provides for an application: storage, compute, database, networking, security, monitoring, and deployment.
- Choose the right AWS service for this project’s next production need.
- Move uploaded inspection media from local disk toward S3-style object storage with safe access controls.
- Understand IAM permissions well enough to avoid overpowered credentials.

## Constraints
- Lessons should stay tied to this project.
- Prefer small production-aware upgrades over broad theory.
- Teach with examples and plain explanations.

## Out of scope
- Deep AWS certification coverage.
- Kubernetes-heavy deployment unless the project genuinely needs it.
- Advanced multi-account enterprise architecture for now.
